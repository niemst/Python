## Testing Your Project / Testowanie projektu

After implementation, test these scenarios:

Po implementacji, przetestuj te scenariusze:

1. **Normal operation** — does it work as expected?

   **Normalna operacja** — czy działa zgodnie z oczekiwaniami?

2. **Network failure** — unplug internet, does it handle gracefully?

   **Awaria sieci** — odłącz internet, czy radzi sobie elegancko?

3. **Invalid input** — enter wrong data, does it validate?

   **Nieprawidłowe wejście** — wpisz złe dane, czy waliduje?

4. **File corruption** — edit saved file with garbage, does it recover?

   **Uszkodzony plik** — edytuj zapisany plik ze śmieciami, czy się odzyska?

5. **Empty state** — start fresh, does it handle no saved data?

   **Pusty stan** — zacznij od zera, czy radzi sobie bez zapisanych danych?
