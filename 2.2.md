## JSON — structured data / JSON — dane strukturyzowane

**Video:**

---

Create `json_demo.py`:

Utwórz `json_demo.py`:

```python
import json
from pathlib import Path

# Python dict / Słownik Pythona
person = {
    "name": "Alice",
    "age": 25,
    "hobbies": ["reading", "coding"]
}

# Save to JSON / Zapisz do JSON
Path("person.json").write_text(json.dumps(person, indent=2))
print("Saved to person.json")

# Load from JSON / Wczytaj z JSON
loaded = json.loads(Path("person.json").read_text())
print(f"Name: {loaded['name']}, Age: {loaded['age']}")
```

Run:

Uruchom:

```bash
uv run python json_demo.py
```

Check `person.json` — it's human-readable!

## CSV — tables / CSV — tabele

[CSV (Comma-Separated Values)](https://en.wikipedia.org/wiki/Comma-separated_values) is like Excel saved as text.

[CSV (wartości rozdzielane przecinkami)](https://pl.wikipedia.org/wiki/CSV_(format_pliku)) to jak Excel zapisany jako tekst.

**Documentation:**

[Python csv module](https://docs.python.org/3/library/csv.html)

**Video:**

[Corey Schafer — Reading and Writing CSV Files (0:00–18:00)](https://youtu.be/q5uM4VKywbA)

---

Create `csv_demo.py`:

Utwórz `csv_demo.py`:

```python
import csv

# Write CSV / Pisz CSV
with open("products.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Name", "Price", "Stock"])
    writer.writerow(["Laptop", 999.99, 15])
    writer.writerow(["Mouse", 29.99, 50])

print("Created products.csv")

# Read CSV / Czytaj CSV
with open("products.csv", "r") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

Run:

Uruchom:

```bash
uv run python csv_demo.py
```

## DictReader / DictWriter — easier way / łatwiejszy sposób

Working with dictionaries is cleaner than lists.

Praca ze słownikami jest czystsza niż z listami.

```python
import csv

# Write with DictWriter / Pisz z DictWriter
employees = [
    {"name": "Alice", "salary": 70000},
    {"name": "Bob", "salary": 60000}
]

with open("employees.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "salary"])
    writer.writeheader()
    writer.writerows(employees)

# Read with DictReader / Czytaj z DictReader
with open("employees.csv", "r") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(f"{row['name']}: ${row['salary']}")
```

## Real-world example: save user data / Przykład z życia: zapisywanie danych użytkownika

This is how I save app settings in my projects.

Tak zapisuję ustawienia aplikacji w moich projektach.

Create `user_settings.py`:

Utwórz `user_settings.py`:

```python
import json
from pathlib import Path

class UserSettings:
    def __init__(self, settings_file: str = "settings.json"):
        self.file = Path(settings_file)
        self.settings = self.load()

    def load(self) -> dict:
        if self.file.exists():
            return json.loads(self.file.read_text())
        return {"theme": "light", "language": "en"}

    def save(self) -> None:
        self.file.write_text(json.dumps(self.settings, indent=2))

    def get(self, key: str, default=None):
        return self.settings.get(key, default)

    def set(self, key: str, value) -> None:
        self.settings[key] = value
        self.save()

# Usage / Użycie
settings = UserSettings()
print(f"Theme: {settings.get('theme')}")

settings.set("theme", "dark")
print(f"Updated theme: {settings.get('theme')}")
```

Run:

Uruchom:

```bash
uv run python user_settings.py
```

## When to use what? / Kiedy czego użyć?

**Use JSON when / Użyj JSON gdy:**

- Data has nested structure (objects within objects)

  Dane mają zagnieżdżoną strukturę (obiekty w obiektach)

- Working with APIs (most use JSON)

  Pracujesz z API (większość używa JSON)

**Use CSV when / Użyj CSV gdy:**

- Data is flat table

  Dane to płaska tabela

- Sharing with Excel users

  Dzielisz się z użytkownikami Excel

## Bonus: pandas for data work / Bonus: pandas do pracy z danymi

For serious data work, [`pandas`](https://pandas.pydata.org/) makes everything easier.

Do poważnej pracy z danymi, [`pandas`](https://pandas.pydata.org/) ułatwia wszystko.

Install:

Zainstaluj:

```bash
uv add pandas
```

Example:

Przykład:

```python
import pandas as pd

# Read CSV / Czytaj CSV
df = pd.read_csv("employees.csv")

# Filter / Filtruj
high_earners = df[df["salary"] > 65000]
print(high_earners)

# Save to JSON / Zapisz do JSON
df.to_json("employees.json", orient="records", indent=2)
```
