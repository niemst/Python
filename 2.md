# BLOK 2 — Praca z plikami i danymi / Working with Files and Data

---

## Cel / Goal

Learn to work with files, handle errors, import modules, and connect to external data sources (JSON, CSV, APIs).

Nauczyć się pracować z plikami, obsługiwać błędy, importować moduły i łączyć się z zewnętrznymi źródłami danych (JSON, CSV, API).

**Why this matters / Dlaczego to ważne:**

Programs need to save and load data — config files, user data, logs, external APIs.

Programy muszą zapisywać i wczytywać dane — pliki konfiguracyjne, dane użytkowników, logi, zewnętrzne API.

File handling and error management are essential for production-ready applications.

Obsługa plików i zarządzanie błędami są kluczowe dla aplikacji gotowych do produkcji.

## Przygotowanie projektu / Project Setup

Before starting, set up your Phase 2 project folder.

Zanim zaczniesz, przygotuj folder projektu dla Fazy 2.

**Step 1: Create folder and initialize uv / Krok 1: Utwórz folder i zainicjuj uv**

```bash
mkdir 02_files_and_data
cd 02_files_and_data
uv init
```

**Step 2: Create .gitignore / Krok 2: Utwórz .gitignore**

Create a file named `.gitignore` with the following content:

Utwórz plik o nazwie `.gitignore` z następującą zawartością:

```
# Python
__pycache__/
*.py[cod]
.Python
.venv/
venv/
.env
*.log

# Data files
*.csv
*.json
!example.json
!example.csv

# IDE
.idea/
.vscode/
```

**Step 3: Initialize Git / Krok 3: Zainicjuj Git**

```bash
git init
git add .
git commit -m "Initialize Phase 2 - Files and Data project"
```

**Step 4: Create README / Krok 4: Utwórz README**

Create a file `README.md`:

Utwórz plik `README.md`:

```markdown
# Phase 2 — Files and Data
```
