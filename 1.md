## 💡 1️⃣ Zmienne i typy danych / Variables and Data Types

A [variable](https://en.wikipedia.org/wiki/Variable_(computer_science)) is like **a labeled box** that stores information — you give it a name and put data inside.

[Zmienna](https://pl.wikipedia.org/wiki/Zmienna_(informatyka)) to jak **opisane pudełko**, w którym przechowujesz informacje — dajesz jej nazwę i wkładasz do środka dane.

Python has several built-in [data types](https://docs.python.org/3/library/stdtypes.html) for storing different kinds of information:

Python ma kilka wbudowanych [typów danych](https://docs.python.org/3/library/stdtypes.html) do przechowywania różnych rodzajów informacji:

- **int** — whole numbers / liczby całkowite (e.g., `42`, `-10`)
- **float** — decimal numbers / liczby zmiennoprzecinkowe (e.g., `3.14`, `-0.5`)
- **str** — text / tekst (e.g., `"Hello"`, `'Python'`)
- **bool** — truth values / wartości logiczne (`True`, `False`)
- **list** — ordered collections / uporządkowane kolekcje (e.g., `[1, 2, 3]`)
- **dict** — key-value pairs / pary klucz-wartość (e.g., `{"name": "Alice"}`)
- **tuple** — immutable ordered collections / niemutowalne kolekcje (e.g., `(1, 2, 3)`)
- **set** — unordered collections of unique items / nieuporządkowane zbiory unikalnych elementów (e.g., `{1, 2, 3}`)

### 📦 Collections / Kolekcje

Collections store multiple items — like containers that organize related data.

Kolekcje przechowują wiele elementów — jak pojemniki organizujące powiązane dane.

```python
fruits = ["apple", "banana", "cherry"]

print(f"Fruits: {fruits}")
print(f"First fruit: {fruits[0]}")
```

```python
# Simple if statement / Prosta instrukcja if
age = 20

if age >= 18:
    print("You are an adult")  # Jesteś dorosły
else:
    print("You are a minor")   # Jesteś niepełnoletni

# Multiple conditions / Wiele warunków
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"Score: {score}, Grade: {grade}")

# Match-case statement (Python 3.10+) — like switch in other languages
# Match-case (Python 3.10+) — jak switch w innych językach
status_code = 200

match status_code:
    case 200:
        message = "OK"
    case 404:
        message = "Not Found"
    case 500:
        message = "Server Error"
    case _:  # default case / domyślny przypadek
        message = "Unknown Status"

print(f"\nStatus {status_code}: {message}")

# Match-case with ranges (combining with if) / Match-case z zakresami (łącząc z if)
grade_score = 85

match grade_score:
    case score if score >= 90:
        grade_letter = "A"
    case score if score >= 80:
        grade_letter = "B"
    case score if score >= 70:
        grade_letter = "C"
    case _:
        grade_letter = "F"

print(f"Grade score {grade_score}: {grade_letter}")

# Comparison operators / Operatory porównania
x = 10
y = 20

print(f"\n{x} == {y}: {x == y}")  # equal / równe
print(f"{x} != {y}: {x != y}")    # not equal / nierówne
print(f"{x} < {y}: {x < y}")      # less than / mniejsze
print(f"{x} > {y}: {x > y}")      # greater than / większe
print(f"{x} <= {y}: {x <= y}")    # less or equal / mniejsze lub równe
print(f"{x} >= {y}: {x >= y}")    # greater or equal / większe lub równe

# Logical operators / Operatory logiczne
is_student = True
has_id = True

if is_student and has_id:
    print("\nYou get a student discount")  # Dostajesz zniżkę studencką

is_weekend = False
is_holiday = True

if is_weekend or is_holiday:
    print("Time to relax!")  # Czas na odpoczynek!

is_raining = True
if not is_raining:
    print("Let's go outside!")  # Chodźmy na zewnątrz!
else:
    print("Stay inside")  # Zostań w środku

# Checking for None — use 'is' not '==' / Sprawdzanie None — użyj 'is' nie '=='
# 'is' checks identity (same object), '==' checks equality (same value)
# 'is' sprawdza tożsamość (ten sam obiekt), '==' sprawdza równość (ta sama wartość)
# For None, always use 'is' — it's more precise and idiomatic
# Dla None, zawsze używaj 'is' — jest bardziej precyzyjne i idiomatyczne

user_name = None
default_name = "Guest"

if user_name is None:
    print(f"\nWelcome, {default_name}!")  # Witaj, Gościu!
else:
    print(f"\nWelcome, {user_name}!")

# Also check 'is not None' / Również sprawdź 'is not None'
email = "user@example.com"

if email is not None:
    print(f"Sending email to: {email}")  # Wysyłanie emaila do: {email}
```

### 🔁 Loops / Pętle

Loops repeat actions — like doing dishes one by one until the sink is empty.

Pętle powtarzają działania — jak zmywanie naczyń jedno po drugim, aż zlew będzie pusty.

#### `for` loop — iterate over sequences / iteruj po sekwencjach

I find `for` loops work well when you know how many times to repeat or have a collection to iterate through.

Stwierdziłem, że pętle `for` działają dobrze, gdy wiesz ile razy powtórzyć lub masz kolekcję do iteracji.

#### `while` loop — repeat while condition is true / powtarzaj dopóki warunek jest prawdziwy

I reach for `while` loops when I don't know in advance how many iterations will be needed.

Sięgam po pętle `while`, gdy nie wiem z góry ile iteracji będzie potrzebnych.

```python
# For loop with enumerate / Pętla for z enumerate

for num in range(10):
```

### 🛠️ Function basics / Podstawy funkcji

🧩 **Zadanie / Task:**

Create a file `functions.py`:

Utwórz plik `functions.py`:

```python
from typing import List, Tuple, Any

# Simple function / Prosta funkcja
def greet() -> None:
    """Display a greeting message / Wyświetl powitanie"""
    print("Hello, World!")

greet()  # call the function / wywołaj funkcję

# Function with parameters / Funkcja z parametrami
def greet_person(name: str) -> None:
    """Greet a specific person / Powitaj konkretną osobę"""
    print(f"Hello, {name}!")

greet_person("Alice")
greet_person("Bob")

# Function with return value / Funkcja ze zwracaną wartością
def add(a: int, b: int) -> int:
    """Add two numbers and return result / Dodaj dwie liczby i zwróć wynik"""
    return a + b

result = add(5, 3)
print(f"\n5 + 3 = {result}")

# Function with default parameters / Funkcja z domyślnymi parametrami
def greet_with_title(name: str, title: str = "Mr.") -> str:
    """Greet with optional title / Powitaj z opcjonalnym tytułem"""
    return f"Hello, {title} {name}!"

print(greet_with_title("Smith"))              # uses default / używa domyślnego
print(greet_with_title("Smith", "Dr."))       # overrides default / nadpisuje domyślny

# Function with multiple return values / Funkcja zwracająca wiele wartości
def get_min_max(numbers: List[int]) -> Tuple[int, int]:
    """Return minimum and maximum / Zwróć minimum i maximum"""
    return min(numbers), max(numbers)

nums = [3, 7, 1, 9, 2]
minimum, maximum = get_min_max(nums)
print(f"\nNumbers: {nums}")
print(f"Min: {minimum}, Max: {maximum}")

# Function with *args (variable arguments) / Funkcja z *args (zmienne argumenty)
def sum_all(*numbers: int) -> int:
    """Sum any number of arguments / Zsumuj dowolną liczbę argumentów"""
    total = 0
    for num in numbers:
        total += num
    return total

print(f"\nsum_all(1, 2, 3) = {sum_all(1, 2, 3)}")
print(f"sum_all(1, 2, 3, 4, 5) = {sum_all(1, 2, 3, 4, 5)}")

# Function with **kwargs (keyword arguments) / Funkcja z **kwargs (argumenty nazwane)
def print_info(**info: Any) -> None:
    """Print key-value pairs / Wyświetl pary klucz-wartość"""
    for key, value in info.items():
        print(f"{key}: {value}")

print("\nUser info:")
print_info(name="Alice", age=25, city="Warsaw")

# Docstrings — function documentation / Docstringi — dokumentacja funkcji
def calculate_area(width: float, height: float) -> float:
    """
    Calculate rectangle area.

    Args:
        width: Rectangle width in meters
        height: Rectangle height in meters

    Returns:
        Area in square meters
    """
    return width * height
```

```python
        return self.hourly_rate * self.get_hours_per_week()
```

```python
from pydantic import BaseModel, Field, field_validator, ValidationError
from typing import List

# Basic Pydantic model / Podstawowy model Pydantic
class User(BaseModel):
    """User with automatic validation / Użytkownik z automatyczną walidacją"""
    name: str
    age: int
    email: str

# Pydantic automatically validates! / Pydantic automatycznie waliduje!
try:
    user1 = User(name="Alice", age=25, email="alice@example.com")
    print(f"✓ Valid user: {user1}")

    # This will fail validation / To nie przejdzie walidacji
    user2 = User(name="Bob", age="invalid", email="bob@example.com")
except ValidationError as e:
    print(f"\n✗ Validation error:\n{e}")

# Pydantic with field constraints / Pydantic z ograniczeniami pól
class Product(BaseModel):
    """Product with validation rules / Produkt z zasadami walidacji"""
    name: str = Field(min_length=1, max_length=100)
    price: float = Field(gt=0, description="Price must be positive")
    quantity: int = Field(ge=0, description="Quantity cannot be negative")
    tags: List[str] = Field(default_factory=list)

product = Product(name="Laptop", price=999.99, quantity=5)
print(f"\n✓ Valid product: {product}")

try:
    # This will fail: negative price / To nie przejdzie: ujemna cena
    bad_product = Product(name="Mouse", price=-10, quantity=1)
except ValidationError as e:
    print(f"\n✗ Validation error: {e.error_count()} error(s)")
    for error in e.errors():
        print(f"  - {error['loc'][0]}: {error['msg']}")

# Custom validators / Własne walidatory
class Employee(BaseModel):
    """Employee with custom validation / Pracownik z własną walidacją"""
    name: str
    employee_id: str
    salary: float

    @field_validator('employee_id')
    @classmethod
    def validate_employee_id(cls, v: str) -> str:
        """Employee ID must start with 'E' / ID pracownika musi zaczynać się od 'E'"""
        if not v.startswith('E'):
            raise ValueError("Employee ID must start with 'E'")
        if len(v) != 5:
            raise ValueError("Employee ID must be 5 characters")
        return v

emp = Employee(name="Alice", employee_id="E0001", salary=50000)
print(f"\n✓ Valid employee: {emp}")

try:
    bad_emp = Employee(name="Bob", employee_id="123", salary=60000)
except ValidationError as e:
    print(f"\n✗ Validation error: {e.errors()[0]['msg']}")

# JSON parsing - Pydantic advantage! / Parsowanie JSON - zaleta Pydantic!
import json

json_data = '{"name": "Charlie", "age": 30, "email": "charlie@example.com"}'
user_from_json = User.model_validate_json(json_data)

# Convert back to JSON / Konwertuj z powrotem do JSON
print(f"✓ To JSON: {user_from_json.model_dump_json()}")

# Type coercion - Pydantic converts automatically! / Konwersja - Pydantic konwertuje automatycznie!
user_with_coercion = User(name="Dave", age="35", email="dave@example.com")  # age is string but gets converted
```

### 🔄 DRY — Don't Repeat Yourself

**Don't Repeat Yourself** means avoid duplicating code — if you write the same thing twice, extract it into a function or class.

**Don't Repeat Yourself** (Nie powtarzaj się) oznacza unikanie duplikacji kodu — jeśli piszesz to samo dwa razy, wyodrębnij to do funkcji lub klasy.

❌ **Bad example / Zły przykład:**
```python
# Repeated code / Powtarzalny kod
print("Processing file1.txt...")
with open("file1.txt") as f:
    data = f.read()
    print(f"Read {len(data)} characters")

print("Processing file2.txt...")
with open("file2.txt") as f:
    data = f.read()
    print(f"Read {len(data)} characters")
```

✅ **Good example / Dobry przykład:**
```python
def process_file(filename: str) -> None:
    print(f"Processing {filename}...")
    with open(filename) as f:
        data = f.read()
        print(f"Read {len(data)} characters")

process_file("file1.txt")
process_file("file2.txt")
```

---

### 💋 KISS — Keep It Simple Stupid

**Keep It Simple Stupid** means write straightforward code — I've learned not to overcomplicate things just to look clever.

**Keep It Simple Stupid** (Zachowaj prostotę) oznacza pisanie prostego kodu — nauczyłem się nie komplikować rzeczy tylko po to, by wyglądać mądrze.

❌ **Bad example / Zły przykład:**
```python
# Overcomplicated / Przekomplikowany
def is_even(n: int) -> bool:
    return True if n % 2 == 0 else False if n % 2 != 0 else None
```

✅ **Good example / Dobry przykład:**
```python
def is_even(n: int) -> bool:
    return n % 2 == 0
```

```python
from typing import List
from datetime import datetime

@dataclass
class Task:
    title: str
    completed: bool = False
    created_at: datetime = field(default_factory=datetime.now)

    def mark_complete(self) -> None:
        self.completed = True

    def __str__(self) -> str:
        status = "✓" if self.completed else "○"
        return f"{status} {self.title}"

class TaskManager:

    def __init__(self):
        self.tasks: List[Task] = []

    def add_task(self, title: str) -> None:
        task = Task(title)
        self.tasks.append(task)
        print(f"Added: {title}")

    def complete_task(self, index: int) -> None:
        if 0 <= index < len(self.tasks):
            self.tasks[index].mark_complete()
            print(f"Completed: {self.tasks[index].title}")
        else:
            print("Invalid task number") # a better way raise ValueError("Invalid task number") (will cover in a future lesson)

    def show_tasks(self) -> None:
        if not self.tasks:
            print("No tasks yet!")
            return

        print("\nYour tasks:")
        for i, task in enumerate(self.tasks, start=1):
            print(f"{i}. {task}")

    def get_stats(self) -> None:
        total = len(self.tasks)
        completed = sum(1 for task in self.tasks if task.completed)
        pending = total - completed

        print(f"\nStats: {completed}/{total} completed, {pending} pending")

# Demo / Demonstracja
def main() -> None:
    manager = TaskManager()

    # Add tasks / Dodaj zadania
    manager.add_task("Learn Python basics")
    manager.add_task("Write first program")
    manager.add_task("Practice with exercises")

    # Complete a task / Ukończ zadanie

    manager.complete_task(2)

    # Show updated tasks / Pokaż zaktualizowane zadania
    manager.show_tasks()

    # Show statistics / Pokaż statystyki

if __name__ == "__main__":
```
